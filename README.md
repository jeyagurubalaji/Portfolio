# 🚀 Jeyagurubalaji - Professional Portfolio

A modern, responsive personal portfolio built with **Next.js, React, TypeScript, and Tailwind CSS**. The portfolio showcases full-stack web applications, mobile applications, and AI/ML projects with live demos, GitHub repositories, certifications, and professional information.

---

## 🛠️ Tech Stack & Tools

| Category | Technologies |
|---|---|
| Frontend | Next.js, React.js, TypeScript, Tailwind CSS, Shadcn UI, Lucide Icons |
| Backend & APIs | Java Spring Boot, Python, FastAPI, Express.js, REST APIs |
| Databases | MongoDB, SQL |
| Mobile Development | Flutter, Dart |
| AI & Machine Learning | Scikit-learn, XGBoost, Pandas, NumPy, NLP, PyTesseract OCR, SHAP |
| Deployment | Vercel, Render, GitHub Actions |

---

## ✨ Key Features

- **Project Showcase** – Displays full-stack applications, mobile apps, and AI/ML projects with live demos and GitHub repositories.
- **Mobile App Downloads** – Provides direct APK downloads for selected Flutter applications.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Modern Dark Theme** – Clean and professional dark-themed interface.
- **Smooth Navigation** – Easy navigation across Projects, Skills, Certifications, Experience, and Contact sections.
- **Professional Profile** – Includes technical skills, certifications, projects, and contact information.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### 1. Clone the Repository

```bash
git clone https://github.com/jeyagurubalaji/Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Portfolio
```

### 3. Install Dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Or:

```bash
pnpm dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```
